# 积木工坊视觉系统

产品依据 [GAME_DESIGN.md](../../GAME_DESIGN.md)、Blender零件与用户参考视频；当前为可玩的v0.5沙盒。本轮用户明确将界面方向改为 Apple / macOS 工具应用风格。详细实现规范见 [brick-workshop/DESIGN.md](../../brick-workshop/DESIGN.md)。

- 模式为Operate。默认进入空白工作台，3D作品与当前操作占据主要空间。
- 界面为白色文档栏、浅冷灰侧栏、系统蓝选态、紧凑分段控件与薄分隔线。采用系统中英文字体栈，避免口号、巨大标题、装饰性品牌底块和层叠卡片。
- 3D零件延续深灰塑料、琥珀透明件、真实凸点孔洞、细小倒角和柔和阴影；界面颜色不替换零件材质。缩略图由同一模型渲染。
- 桌面保留顶部搭建/变形/试车、左侧两列零件库、中央工作台、右侧属性或机构设置及底部编辑工具。用户明确要求Apple通透毛玻璃：覆盖场景的工具条和编辑面板使用60%至66%白色、26px模糊、150%饱和度、明亮细边和内侧高光；文档栏和侧栏保持安静实底。
- 手机搭建时使用底部横向零件库，变形和试车时收起；文档动作、颜色和主要触控按钮保持44px操作目标。低高度面板内部滚动。
- 控件具有可访问名称、键盘焦点和禁用态；原生对话框保留焦点与Escape操作。无结果、加载、放置冲突、保存失败和恢复备份均有明确状态；减少动态偏好关闭装饰动画。用户明确选择的站点毛玻璃优先于系统减少透明度偏好，底部可见“毛玻璃”开关可随时切成实底并保存选择；未明确选择或背景滤镜不可用时提供实底回退，不修改系统设置。
- 取件后进入放置模式，Esc返回选择；右键环绕，滚轮缩放，Shift加右键平移。属性内保留位置微调、组件整体移动和悬空组件落地动作。
- 自动保存显示状态，导入失败保留作品，已有作品的新建操作继续使用明确确认。恢复旧草稿可下载原文件。
- 功能模块机械标牌与小地图保留其语义颜色和现有行为。关节父子组件可点选，命名姿态、动力试车、电量与触控驾驶继续可用。
- 搭建规则、连接判断、碰撞和承托约束由模型逻辑维护；界面展示合法性与拒绝原因，所有修复操作继续受撤销和存档保护。
