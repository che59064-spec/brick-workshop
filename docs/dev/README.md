# 开发档案

本目录公开「积木工坊」从 v0.1 到 v0.6 的开发过程：设计取舍、逐版本验证记录与已知限制。
当前可运行的代码、模型和说明见仓库根目录。

## 版本演进

| 版本 | 重点 |
| --- | --- |
| v0.1 | 静态编辑器（已被后续版本替换） |
| v0.2 | 47 种零件、自由搭建、关节与姿态、动力试车、浏览器存档 |
| v0.3 | 操作优化：微调、模块标牌、小地图、窄屏仪表 |
| v0.4 | 搭建逻辑修复：旋转、吸附、碰撞与高度平面 |
| v0.5 | 接合与支撑：标准接口、凸点承重、悬空拦截 |
| v0.6 | macOS 风格界面、毛玻璃切换、销孔精确配合 |

自动测试从 v0.2 的 33 项增长到 v0.6 的 113 项，逐版本明细见 [PROGRESS.md](PROGRESS.md)。
