# 参考画风纠正

用户反馈：参考是 Blender 制作，当前画风不一致。已询问是继续网页游戏并重做画风，还是转入 Blender 制作；答复前不改变项目交付形态。

## 对照画面观察

参考：视频第 20、26 秒画面（第三方内容，未随仓库公开）。当前：[早期编辑器截图](../screenshots/editor-preview.jpg)。

| 层面 | 参考画面 | 当前问题 | 修正目标 |
| --- | --- | --- | --- |
| 模型轮廓 | 短粗机身、后掠翼、两侧复杂模块，部件紧密交错 | 简单十字薄板与高位座舱，缺少机械层次 | 先重建一个形体比例接近的机械示范，使用独立零件 |
| 结构件 | 孔梁、底部管柱、铰链、栅格、轴销、斜坡与圆筒 | 大部分只有方砖与平板，缺少对应零件 | 增加核心机械零件，明确连接与活动轴 |
| 主体灰色 | 深炭灰大面积，浅灰仅为辅色 | 渲染后灰色发白、浅灰翼面占比过大 | 用固定相机与参考比对主体明暗和灰色面积 |
| 材质 | 细腻塑料，边角有小高光，琥珀件有厚度 | 面片色块感强，玻璃大且发黄 | 校准光照、粗糙度、透明件厚度与尺寸 |
| 光影 | 米灰背景，柔光，接缝与凹槽有遮蔽层次 | 白色网格主导、接触阴影很弱 | 暖灰摄影棚与可切换网格，补足接触遮蔽与软阴影 |
| 镜头 | 模型为主体，近距离三分之四角度 | 远景工作板与工具界面压过模型 | 编辑保持工具，预览用模型优先的镜头和背景 |

视频能确认的外观作为目标；精确隐藏结构、尺寸与渲染参数仍需推断。当前第一版只能说明编辑器功能可运行，不能说明画风已匹配。
