## 2. 分帧事实

### F08：中央装配结构

1. 中央为纵向灰色框架，近端有矩形开口，开口内部可见一个金黄色圆形局部。
2. 近端外侧有向下伸出的夹口状小接口；截图只支持其外形，不确定具体夹具型号。
3. 上表面并排呈现三条长短不同的开口凹槽，凹槽内可见圆形管柱。中间较长，两侧较短。
4. 两侧凹槽件近端各有圆筒状铰接外形和叉口，轴向大致横跨零件宽度。
5. 画面右侧存在浅灰侧挂连接座，圆孔内可见鲜蓝色销端；旁边有金黄色薄层。

**建模意义**：这些开口和管柱需要真实负空间与厚度。把它们换成朝上的普通圆凸点，会改变最显眼的机背识别特征。

### F16：飞机装配视角

1. 金色透明座舱在画面上方，位于细长机鼻轴线上；座舱两侧有深灰圆柱和金黄色环状层。
2. 中央三条开口凹槽仍清晰可见；近端中央存在竖向格栅/多道横槽外形。
3. 左右为镜像布置的宽模块，含浅灰薄板、深灰方块、圆形端面/侧挂接口与斜角翼片。
4. 大片浅灰薄板不是一个连续整体：能看到独立凸点、细长浅灰条及其间接缝。

### F18：侧模块增加覆盖件

1. 机位和中央框架与 F16 接近。
2. 双侧各增加了向内延伸的浅灰筒状末端，以及深灰盖件/斜面覆盖。
3. 左右外端的格栅、楔形翼片和浅灰底层仍可识别。

**阶段判定**：F16 → F18 更符合装配展示中的添件过程。仅凭这两帧不能把新出现的盖件解释成已有零件自动折出来。

### F20：完整飞机

1. 前端是细长深灰楔形机鼻，其后嵌入小块透明琥珀色座舱。
2. 座舱两旁是成对深灰圆柱，靠近座舱的一端有金黄色环状点缀。
3. 机身中央为带矩形开口的框架，内部金黄色局部仍可见；机背的三条反装凹槽件形成主要纵向线条。
4. 两侧深灰模块前方各有一个浅灰中空圆筒口。这里只能确认“喷口样外形”，不能从截图认定其真实动力功能。
5. 外端有成对三角/梯形翼面和格栅面板，模块之间有可读的黑暗间隙。
6. 飞机轮廓由多层小件和侧挂件形成，而非几片大薄板加一块座舱。

粗略图像定位（用于取景，不作为世界尺寸）：模型约占 x=100–680、y=420–845，误差约 ±15 像素。横向占画面宽度约 80%，机身完整可见。

### F22：双侧模块展开

1. 中央框架、三条凹槽和机鼻/座舱总成仍保持可识别的飞机轴线。
2. 左右大模块向外展开，形成接近水平的长臂状轮廓；两侧最外端部分被画面边缘裁切。
3. 原先较紧凑的模块暴露出浅灰双长条、深灰格栅和中间连接块。
4. 截图不能单独确定这是单一轴旋转，还是多关节展开的叠加结果；不能由投影形状推导准确角度。

### F24：直立中间态

1. 已出现两条分离的腿和两只脚，脚底接近地面；腿部能看到浅灰长条、深灰前盖、格栅/孔洞、外侧翼片及浅灰圆形关节端面。
2. 髋部横向圆柱/轴件的画面右端露出蓝色圆形销端。
3. 胸前为两块金黄色面板，中间是一条带圆凸点的深灰纵向板；肩旁的细长灰色模块已经向下悬挂。
4. 原来的机鼻/框架总成仍竖在躯干上方，能看到矩形开口和内部黄色局部，顶部超出画面。

**取景限制**：该帧只能验收中间机构与下半身，不能用于完整模型高度或最终头部比例验收。

### F26：完成的人形

1. 头部是小尺寸深灰楔形/斜顶块，颈部较短；头后左右能看到横向圆筒式连接外形。
2. 胸上部由左右深灰装甲块构成，一侧可见四面收尖/金字塔样面板。胸部下方两块金黄面板并列，中间为深灰凸点板。
3. 肩部外露圆形连接结构；上臂和前臂以窄长深灰件为主，手端没有大型拟真五指。
4. 腰细，髋部有横向圆柱结构与蓝色销端；腿明显长于躯干，浅灰内层和深灰外层相互错开。
5. 小腿外侧保留楔形翼片、矩形孔/槽与格栅层次；脚部为向前伸出的深灰楔块。
6. 机鼻/座舱总成不再占据头顶正上方；其最终背面停放位置被当前正面视角部分遮挡。

粗略图像定位：完整人形约占 x=115–615、y=250–1035，误差约 ±15 像素。全高约 780 像素，头部约 60–75 像素。验收时先比较长腿、小头、窄腰的比例，避免做成大头短腿的卡通机甲。

## 4. 候选关节树与动作顺序

下面是用于 Blender 原型的候选层级。它服务于保持部件身份与验证运动路径，不代表已还原真实搭建结构。关节轴向、轴心和限位必须在后续模型/连续帧核对中确定。

```text
R00 作品根节点（整体位置/朝向）
└─ M40 胸腰核心 [作为原型暂定根刚体]
   ├─ J10 机鼻总成折叠 [候选]
   │  └─ M00/M10 框架、机鼻、座舱与成对圆柱
   ├─ J50 颈部/藏头 [待核实]
   │  └─ M50 头部
   ├─ J30-L / J30-R 肩部旋转 [位置可由人形定位]
   │  └─ M30-L/R 窄长臂总成
   │     └─ 肘/端部微调 [是否独立活动待核实]
   └─ J20-L / J20-R 髋部展开 [候选]
      └─ M20-L/R 原机侧大模块
         ├─ 膝部展开 [候选]
         └─ 脚/外侧楔翼折转 [候选]
```

原型中的臂/腿命名可以先服务于最终人形，飞机模块映射须另存备注；不要把尚未验证的对应关系写进不可逆模型命名或固定拓扑。

| 阶段 | 截图支持的变化 | 原型动作建议 | 证据边界 |
| --- | --- | --- | --- |
| 装配 | F08 → F16 → F18 有新增外层件 | 如要演示拼装，使用独立装配轨道 | 这是零件加入，不能冒充完整作品的变形 |

需补证据：20–26 秒的连续变形片段或 21/23/25 秒附近的更密集帧；飞机底面、机器人背面；关键铰链的近距离视角。现有七帧不能证明完整机械闭合。

## 6. Blender 材料与摄影棚起调原则

以下为待渲染验证的起调建议，不是从视频测出的原始参数。

- **主体塑料**：Principled BSDF，Metallic 接近 0；优先保证中性深灰。Roughness 可先在 0.25–0.4 内试调，IOR 约 1.45–1.5，少量 Coat。灰色不能靠金属度和蓝色反光来表达。
- **浅灰结构件**：与主体属于同一塑料家族，只改变基础色；避免亮成纯白而丢失轮廓。
- **金黄件与蓝销**：分配独立材质，保留小面积饱和色；金黄胸片不自动等同金属材质。
- **座舱**：独立有厚度的透明琥珀壳，不能仅用低不透明度平面；以内部结构可读、边缘有反射和色彩累积为验收依据。
- **几何**：凸点顶部、孔口和装甲边缘需要可见的小倒角；大面保留平面，不能全部圆润化。槽内管柱与接口必须有真实深度。
- **灯光**：以大面积柔光形成主要方向，弱填充保留槽内暗部；环境强度与主光比例共同调节。先用中性灰测试件核对照明，再对完整模型调色。
- **地面**：暖米灰漫反射表面，可有非常轻微的粗糙度变化；不加入抢眼纹理或镜面反射。
- **色彩管理**：记录所用视图变换、曝光、灯光强度与材质版本，整组 A/B 图使用相同设置。不能从视频压缩后的像素色直接倒推 Base Color。
- **相机**：先匹配投影轮廓，再调焦距与距离；参考仅显示较弱透视，不能断言一定是正交相机或给出“原始焦距”。

## 7. 每轮可复核验收清单
