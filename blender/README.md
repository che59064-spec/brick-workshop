# Blender 零件与变形研究

- `output/parts_library.blend`：47 种零件的可编辑资产库，包含空白 Sandbox 与零件目录场景。
- `output/transformer_study.blend`：77 个独立零件构成的飞机／人形变形研究初稿。可选择 `CTRL · Transformation`，调整自定义属性 `transform` 查看两个形态。
- `output/aircraft.png`、`humanoid.png`、`parts_catalog.png`：由项目模型生成的渲染图。
- `scripts/` 与 `tests/`：模型构建、导出及验证脚本。运行需本地安装 Blender 和对应 Python 环境。
- `ldraw/`：项目使用的精简 LDraw 原始文件及许可；详见 `CAreadme.txt`、`CAlicense.txt` 和 `manifest.json`。

模型仍为研究初稿，尚未完成全路径自碰撞和真实机械装配验证。原始素材版权与许可归对应作者；详见[仓库首页](../README.md)的来源说明。
