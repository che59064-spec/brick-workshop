# 积木工坊界面规范

本轮界面采用用户指定的 Apple / macOS 工具应用语言。产品任务与范围见 [PRODUCT.md](PRODUCT.md)，上级项目约定见 [../DESIGN.md](../DESIGN.md)。工作台属于 Operate 模式：零件、作品与当前编辑任务构成主要层级。

## 视觉方向

白色文档工具栏、浅冷灰零件侧栏、系统蓝选态、紧凑分段控件与薄分隔线。用户进一步明确要求 Apple 的通透毛玻璃材质，画布浮动工具与编辑面板据此采用可见的磨砂玻璃。界面避免宣传页式大标题、口号、彩色品牌底块和多层卡片。深灰塑料、琥珀透明件、凸点、孔洞与柔和阴影继续由真实 3D 零件承担视觉表现。

字体直接使用系统栈：`-apple-system, BlinkMacSystemFont, Segoe UI, PingFang SC, Microsoft YaHei, sans-serif`。Windows 使用可用的系统字体，不额外加载网络字体。

## 颜色与层级

| 用途 | 值 |
| --- | --- |
| 主文字 | `#1d1d1f` |
| 次级文字 | `#62666d` |
| 零件侧栏 | `#f0f1f4` |
| 文档栏 | `#ffffff` |
| 分隔线 | `#d9dce1` |
| 当前选择、交互强调 | `#007aff` |
| 选态浅底 | `#e4efff` |
| 删除与操作错误 | `#bd3029` |

系统蓝用于选中零件、编辑工具、吸附和主按钮。暖色只承担恢复提醒、支撑修复提示和地图目标等已有语义。桌面标准正文 12–13px，零件名称与工具 11px，尺寸与状态 10px；标题限定在当前面板的 14–21px 层级。

## 布局与控件

- 桌面采用 64px 顶部文档栏、260px 左侧零件库与26px状态栏；宽屏侧栏增加至282px。顶部依次为品牌和可编辑作品名、搭建/变形/试车分段、文档动作。
- 零件库包含搜索、原生类别选择器、可滚动两列缩略图及底部颜色。缩略图沿用现有模型渲染，名称和尺寸直接可读。
- 画布顶部保留工作台信息与视角分段。属性、关节与试车仪表使用同一边界、圆角和滚动规则；内容较长时在面板内部滚动。
- 编辑工具条贴近画布底部；图标、选态和快捷键服务实际编辑功能。底部另放吸附、网格、旋转轴与帮助。
- “移动整个组件”和“将悬空组件放回地面”使用可换行宽按钮，避免挤入并排小动作。
- 关节设置、命名姿态、预览进度、试车小地图和触控驾驶均延续现有功能与 DOM ID。

## Apple 毛玻璃材质

玻璃只用于直接覆盖3D场景的悬浮层：编辑工具条、视角控件、吸附工具组、放置提示、姿态条、属性、机构、试车仪表、示例信息和驾驶控制。白色透明度在60%至66%，背景使用 `backdrop-filter: blur(26px) saturate(150%)`，使背后的场景色与模型色进入材质。白色细边、顶部内侧高光、向下偏移的柔和阴影共同提供厚度。

文档栏和零件侧栏保持清晰实底，避免全屏模糊。输入数值、地图和蓝色选态使用更实的底色，主文字维持 `#1d1d1f`。

用户在本产品中明确选择毛玻璃，因此站点默认使用 `body[data-material="glass"]`，该显式站点选择优先于系统减少透明度偏好，不修改操作系统设置。工作台底部提供可见的“毛玻璃”开关，可随时切换 `body[data-material="solid"]` 实底并在本浏览器保存选择。实底模式始终关闭背景滤镜，使用 `#f5f7fb`。没有明确站点选择时，`prefers-reduced-transparency` 才触发实底回退；浏览器不支持背景滤镜时始终回退实底。

## 窄屏、低高度与可访问性

600px以下改为两行文档栏和底部零件抽屉：上方仍是3D画布，零件横向滚动，颜色保留完整触控目标。变形与试车模式收起零件库。顶部文档动作保留可访问名称和图标，作品名仍可编辑。

窄屏及粗指针设备的主要按钮使用44px触控目标。属性和关节区域保留画布上下操作空间并可滚动；低高度窗口压缩非操作间距和缩略图。原生 `dialog` 保留焦点管理、Escape关闭与窗口内滚动。所有交互有可见键盘焦点，禁用态不隐藏功能；加载、无结果、放置冲突、保存失败、恢复通知与toast具有独立状态。

动效只用于短暂控件反馈和加载呼吸。`prefers-reduced-motion` 关闭动画及过渡。画布和模型渲染不在本 CSS 的行为修改范围内。

## 维护与验证

界面样式统一在 [src/style.css](src/style.css)，按基础、文档/零件、画布编辑、机构/试车、状态/弹窗及响应式分段。修改现有规则，避免继续在文件末尾叠加同选择器覆盖。

本轮样式已通过 `npm run build`。浏览器中的1280×800、390×844和低高度布局由主任务统一验收，视觉截图与行为结果以主任务的实际检查为准。
